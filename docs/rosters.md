# 自定义排班与长班

## 入口与默认行为

排班是主动开启的可选功能，入口位于「我的 → 工作设置」「薪苦日历 → 排班设置」及工作旅程的「阶段排班」。未启用时保留原来的固定作息、大小周、首页布局与底部导航。新表单使用 beUI 日期、时间、选择、输入、按钮和开关，班次颜色跟随主题。

## 设置步骤

1. 选择所属工作和生效日期；选择手动安排、每周重复或 1–366 天自定义循环。
2. 建立班次模板，填写开始时间、结束时间和结束日偏移。次日同一时刻代表 24 小时，允许最长 31 天。一天可安排多个不重叠班次。
3. 按需要展开「休息与班次金额」，添加多段计薪或不计薪休息、每班工资及补贴。休息时间必须落在班次内，不能重叠。
4. 设置循环顺序与循环第 1 天日期。长班覆盖的后续日期不需要再次安排该班，日历会标为「续班」。
5. 选择计薪方式，预览班次、自然日计薪工时及生效月份预计收入，再确认保存。

无规律轮班可选手动安排，在「单日 / 批量调整」中选择日期，添加模板并修改。支持连续 1–366 天套用、复制前一周对应日期、调整为休息、恢复常规规则。临时调整不会移动循环相位。恢复规则后编辑器会重新显示已保存的班次。

## 计薪口径

| 方式 | 基本工资 | 班次补贴 |
| --- | --- | --- |
| 保留月薪 / 年薪 | 使用原工资及扣除设置，按当月自然日分摊；任职期间休息仍保留基本工资 | 班次完成时另计 |
| 按小时 | 使用手填到手时薪，按计划经过的计薪时间，或按记录的实际计薪时间计算；实际基础工资封顶于计划工时，超出部分按超时选项结算 | 班次完成时另计 |
| 按班 | 使用每个班次填入的到手金额；按计划时到计划结束发放，按实际时需实际记录覆盖整班的计薪时段 | 与班次工资一同发放 |

不计薪休息会从计薪工时中扣除；计薪休息保留在计薪工时中。现有工时统计沿用计薪时间口径。按实际结算时没有手工修正记录的日期仍按计划推算；可通过首页「修正时间」或弹性计时记录真实出勤。

超时选项包括手工确认、不额外计薪、时薪倍率和整次固定金额。固定超时金额在工作记录结束后发放。已经通过独立加班记录结算的部分不再重复自动计入班次工资。没有计划的临时工作应先补班次；仍可用每日最终工资处理不规则结算。

「每日最终工资」支持 0，覆盖该开班日自动基本工资、班次补贴和自动超时工资，优先于该日的出勤工资设置；独立的加班账目保留。提前下班、部分班次发放、特殊津贴组合等可在这里手工确定结果。产品不自动推断行业合同、税费或法定加班倍率。

时间单价默认使用该工作、该计薪方式的当月原计划工时折算。固定月薪只使用当月启用月薪排班且在任职范围内的工资份额，避免月中启用或入离职放大单价；可填写每月标准计薪工时覆盖默认分母。零工时时单价为 0，固定月薪仍保留。按班折算单价不含补贴。

## 日期归属与历史

- 整个长班的出勤、修正记录、工资和补贴归属于开班日期。后续日期的日历「续班」提供开班日调整链接。后续日期本身的出勤设置只影响该日新开班次和日薪；修改跨日班的中途休息需到开班日修改休息时段。
- 正常计薪工时跨月按实际时间拆分，不重复计入每个月。按班收入只在开班月计入一次。独立加班和摸鱼记录沿用现有开始月统计规则。
- 已开启长班可以延续至最后任职日之后，但不能与下一工作阶段的班次重叠。工作旅程保存时会检查相关排班冲突。
- 常规规则按所属阶段、生效日期保存版本。修改规则默认从次日生效；明确选择已有生效日期会更新该版本，影响其负责的历史日期。更早版本和实际计时记录保留。
- 修改生效日期之前的月份不会因未来排班而切换统计口径。关闭排班从所选日期恢复原作息。
- 保存使用设置快照校验和同源锁；其他页面已修改配置或存储失败时不覆盖现有数据，保留编辑草稿。

## 假期与手工出勤

国家节假日是否覆盖常规排班由开关决定，且需要国家日历已启用。补班日期不会凭空生成班次；需循环本身有班或手工安排。

个人假期默认覆盖常规排班，也可以关闭。假期以开班日期判断，开始后的长班不会在午夜突然中断。明确的单日排班优先于常规假期，可选择沿用假期工资，避免值班与假期工资重复计算。日历的手工出勤决定该开班日是否工作；工资优先使用排班每日最终金额，其次手工出勤工资，再按假期及排班规则处理。
