# 数据备份与跨端迁移

入口：**设置 → 数据备份与迁移**。网页 / PWA、安卓和 Windows / macOS 桌面端使用同一种 JSON 备份格式，处理过程不经过应用服务器。

## 从网页或安卓迁移到电脑

1. 在原设备保存设置，结束摸鱼、加班或弹性工作计时，并完成结算。安卓先打开应用，让桌面组件的操作同步进来。
2. 点击「导出备份」。网页和桌面端发起下载；安卓弹出系统文件管理器，选择保存位置。确认文件已经保存，再把 JSON 文件传到电脑。
3. 在电脑打开 MoneyDance，进入同一入口，点击「选择备份导入」。核对导出日期、来源和记录数量。
4. 关闭其他正在使用的 MoneyDance 页面，勾选确认替换，点击「确认导入并刷新」，在确认框中完成导入。
5. 检查工资、账本和心愿。导入前的本机数据可通过「导出导入前备份」保存；如需还原，可再将该文件导入。

功能发布前的安卓安装包没有文件备份插件，需要先覆盖升级到包含此功能的新 APK；原应用数据应保留。网页需访问原来存有数据的网站和浏览器，不能从另一域名或另一浏览器直接读取原数据。桌面端也需要安装包含本功能的版本。不要为迁移卸载原应用或清理浏览器数据。

## 包含与不包含

包含工资和按日期保存的规则、工作旅程、假期及排班、出勤、工作记录、手工账本和账目关联、心愿及分配历史、物品、摸鱼和加班记录、永久成就、节假日设置、主题、移动导航栏和桌面心愿选择。记录的 ID、金额、业务日期、时区信息按原值保存，不在导入时按新设备日期重写。

不迁移正在进行的计时、历史删除的撤销操作、更新检查缓存、系统权限、安卓组件实例、开机启动、桌宠照片和动作包。桌面端已有的桌宠素材和设置不会被业务数据导入覆盖。需要迁移自定义桌宠时另行导入原动作包。

导入是**覆盖替换，不合并**。重复导入不会追加重复记录；备份中没有的业务分类会清空目标端对应分类。尚未执行的计时预约保留为取消状态，避免在两台设备重复开始；已完成的预约记录保留。导出后源设备数据不变。两个设备之后的新记录各自保存，不会自动同步。

文件是包含个人财务信息的明文 JSON，请自行选择可信的保存、传输位置。每个文件最大 8 MB；存储空间不足时会拒绝导入或回滚，不能通过清空旧数据绕过备份步骤。

## 数据保护和版本

- 文件带 `format: moneydance-backup`、`version: 1`、导出时间和来源；未知版本、无效格式、异常嵌套、无效记录、重复 ID、心愿分配不一致等在写入前拒绝。
- 使用业务字段白名单，不复制整个 localStorage，也不接受任意存储键写入。
- 预览后本机数据变化时要求重新选择、核对文件，避免用过期预览覆盖新记录。
- 导入前先持久保存原数据及恢复标记，写入失败时恢复原值；如果应用意外关闭，启动时先恢复未完成的导入，再加载业务页面。恢复失败时暂停进入业务页面，避免用不完整数据继续计薪。
- 成功后保留最近一次导入前备份。再次导入会更新这份备份，重要版本请另外导出文件留存。

安卓文件操作通过 Storage Access Framework 的创建/打开文档界面，不申请全盘存储权限。参见 [Android 官方文档](https://developer.android.com/training/data-storage/shared/documents-files)。系统文件选择器允许用户选择云盘位置，此时文件存储由所选提供方处理。

## 本次验证

- 核心自动测试覆盖所有共享数据分类、旧字段兼容、重复导入、坏文件、活动计时、预览过期、空间不足、回滚与中断恢复；安卓桥接测试覆盖保存、取消、旧 APK 和失败提示。
- 浏览器实际下载 JSON，再在独立移动尺寸浏览器中预览、取消、导入、刷新并导出原数据备份；工资、心愿、账本和主题均保留。
- 真实 Electron `moneydance://app` 页面导入网页备份，再成功导出桌面备份。使用独立临时数据目录，没有操作实际用户数据。
- 安卓插件通过 `:app:compileDebugJavaWithJavac` 编译；尚未完成安卓真机系统文件选择器和云盘提供方的端到端验收。

本次修改不自动发布网页、APK 或各桌面安装包。发布时需同时更新源端的导出入口和目标端的导入入口。
