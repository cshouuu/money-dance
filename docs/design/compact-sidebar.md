# 收起侧栏调整（0.4.7）

收起时原先只把文字设为透明，品牌文字、分组标题、菜单文字和隐私说明依然占位，挤压导航区并出现宽大的 Windows 原生滚动条。

收起态改为 72px 图标栏，真正移除隐藏文字的布局占位。品牌、展开按钮、导航和底部入口居中；图标使用统一点击区域，分组以细线区分，选中项采用主题浅色底和短竖线，去掉挤在图标旁的小圆点。导航链接补充独立 aria-label，鼠标悬停可通过 title 识别名称。

600px 以上窗口使用紧凑间距完整展示 12 个桌面入口；低于可容纳高度时保留原生滚动行为并隐藏滚动条，键盘聚焦仍能滚入可见区。展开态宽度和移动端导航维持原有布局，所有界面颜色使用现有主题变量。

验证：真实 Electron 页面在 768、688、600、520px 高度下检查图标居中、菜单可达性和无多余文字占位；验证展开、路由跳转及 820px 窄屏布局。TypeScript、生产构建和 PWA 校验通过。本次生成 Windows x64 0.4.7 安装包。

后续已同步构建 Windows ARM64、Mac M 系列和 Mac Intel 的 0.4.7 安装包，各自原生平台的安装、重启和集成验证通过。构建记录见 ../DESKTOP_BUILDS.md。
