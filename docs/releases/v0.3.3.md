# MoneyDance v0.3.3 更新说明

这次更新，让工作时间记录更灵活，也让每一天多一点盼头。

## 工作时间，按实际安排记录

- 修正工作时间时，支持填写过去或未来的结束时间。过去时间作为实际下班时间；未来时间作为预计下班时间，到点停止计薪；留空则持续计薪，手动结束。
- 提前下班可以手动结束工作，首页同步显示修正后的结束时间。
- 修复周末选择「今天也上班」后未正确扣除午休、提前显示工作已满的问题。

## 首页新增盼头倒计时

- 查看距离发薪、下班、下一段休息、休息日和节假日的时间，发薪日优先展示。
- 优化今日概览，集中查看时间单价、摸鱼收益和加班收入。
- 调整桌面首页布局，消除大块空白，保留本月战绩与心愿清单。

## 支持多段休息

- 可设置午休、晚休等多个命名休息时段。
- 未计薪的休息时段按设置扣除，重叠部分不会重复扣除；首页展示最近一段休息。

## 加班、摸鱼支持预约

- 可以添加多个未来时段，每条预约执行一次；未开始的预约支持修改、取消。
- 应用打开时到点开始；设置结束时间后到点停止，留空则手动结束。
- 关闭应用后再次打开，会按预约时间补算记录。当前不含每天／每周循环预约和系统后台提醒。

## 心愿起始日期可自定义

- 支持历史、今天及未来日期：可补计此前的工作收入，也可提前安排未来心愿。
- 未来心愿开始前进度为 0，并显示「尚未开始」；到日后自动累计，预计达成时间从选定日期起算。
- 心愿进度继续按工作收入折算，不代表实际存款；多个心愿分别计算，不分摊收入。

## 界面细节修复

- 修复心愿起始日期、物品分类与其他输入框不对齐的问题。
- 加班预约类型选择统一使用 beUI 下拉组件。
- 修复首页「今天弹性上班」按钮对齐问题。
