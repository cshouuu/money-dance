# MoneyDance v0.3.0｜界面焕新，更清晰地看见每一份收入

这次更新，我们重新整理了 MoneyDance 的界面和配色，让手机与电脑上的使用体验更加统一、清晰。

- **12 套主题，随心切换**：重新搭配页面背景、收入主卡和按钮颜色，提升文字清晰度；选主题时即可预览实际效果，选择会自动保存。
- **首页信息更好读**：发薪日、时间单价、摸鱼收益和加班收入以四张等大小卡片展示，优化手机和电脑上的留白与对齐。
- **薪资设置更好用**：设置区块支持折叠，工资扣除项卡片重新排版，下拉框、日期和时间选择器统一视觉风格；数字输入可清空后重新填写。
- **心愿卡片更紧凑**：进度、所需工作时间和预计达成时间更加清楚；跨年预计时间会显示年份，到达预计时间后显示对应提示。
- **摸鱼进度更直观**：手机端“这份工资，摸回多少了？”采用圆形进度图，多项进度可以并排查看。
- **细节体验修整**：优化弹窗圆角、记录卡片按钮位置和侧边栏收起状态，统一网页、浏览器图标与 Android 应用图标，并让 Android 页面边缘背景跟随主题。

网页版刷新后即可体验；Android 用户可在应用内检查更新，或前往下载页安装新版。
