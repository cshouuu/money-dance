# MoneyDance v0.5.0 更新公告

这次更新主要解决两件事：工作设置更容易理解，多份心愿合理分配同一份收入。

## 工资与出勤设置更清楚

- 调整工资和作息时，可选择生效日期，保留之前的规则；保存前可查看生效范围和当月工资预估。
- 大小周直接显示本周、下周上哪几天班。手动排班引导设置首个班次，减少只建模板却漏排班的情况。
- 请假按全天或半天选择，再选不计薪、工资照常或另设金额，带薪假设置更直接。
- 修正月中从固定作息转为新排班时的月薪分摊问题；旧的月平均天数估算方式继续保留，并说明计算口径。

## 心愿按顺序攒，收入不重复计算

- 多个心愿共享一份收入，先攒当前目标，攒够后自动接着攒下一个。
- 点击“优先攒这个”即可调整顺序，之前已分配的金额保留，后续收入按新顺序分配。
- 删除未买心愿会释放其已分配金额；标记已买后，花掉的金额不会再次计入其他心愿。
- 旧心愿先预览新进度，确认后再切换。心愿页、首页卡片和 Android 心愿组件同步使用分配结果。

心愿进度仍按工资与计薪工作时段估算，不代表实际存款余额。

## 记录填错后，更容易修改

- 工作旅程支持删除工作经历，删除前可查看影响，删除后可撤销；保留原始出勤、计时和手工收支记录。
- 摸鱼记录和普通加班记录支持直接修改时间并预览金额，加班关联账目同步更新。
- 修复固定月薪的摸鱼工资里程碑在休息日或空排班时显示异常的问题。

Android 正式版可覆盖升级已有正式版。独立测试版与正式版数据不互通。
