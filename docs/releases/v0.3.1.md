# MoneyDance v0.3.1

本次更新围绕心愿管理、固定作息和物品分类完善用户反馈。

- 心愿支持自定义起始日期，可从过去某天开始累计进度。旧心愿继续使用原创建时间，无需迁移。
- 支持编辑心愿名称、目标金额和起始日期；涨价后同步重算进度与预计完成时间。
- Android 新增 4×2「心愿进度」桌面组件。在心愿清单中指定最多 3 个心愿，点击组件中的名称切换饼图，查看已积累金额与目标金额。
- 心愿组件约每小时刷新一次；打开应用或修改相关数据后立即同步。系统节电和桌面调度可能延迟后台刷新。
- 休息日可选择「今天也上班 · 按平时作息」，正确扣除未计薪午休；也可单独选择弹性上班。
- 固定作息支持提前结束工作，以及补录、修正实际上下班时间。记录与计划计薪时段取交集，扣除未计薪休息，并同步更新首页、账本、心愿进度和桌面组件；跨午夜班次仍归属于开始日期。
- 物品分类支持选择预设或直接输入，自定义分类只随本次物品保存，不进入预设分类列表。

## 使用说明

Android 更新后，先在「心愿清单 → 桌面心愿」中选择心愿，再从系统桌面的小组件列表添加「Money Dance · 心愿进度」。未选择的空位不展示；购买或删除的心愿会自动从组件中移除。

心愿组件不需要常驻通知，也不会为了刷新启动前台计时服务。后台根据应用最近同步的工作安排计算进度；固定作息缓存覆盖未来一年，届时提示打开应用刷新。没有预计结束时间的弹性计时最多外推 36 小时，重新打开应用后校准。

本次不包含按小时请假、历史数据批量编辑删除、月薪回算、有效工时时薪的新口径。
