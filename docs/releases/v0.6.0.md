# MoneyDance v0.6.0

这次正式带来电脑桌面版和跨端数据迁移。已有网页、安卓数据，可以通过备份文件带到电脑继续使用。

## 数据备份与迁移

- 在「设置 → 数据备份与迁移」导出 JSON，再到另一台设备选择文件导入。
- 保留工资与历史规则、账本、心愿、工作旅程、排班、出勤、工作记录、物品、摸鱼与加班记录、成就和主题。
- 导入前核对来源、日期和记录数量，确认后替换本机数据；自动保留导入前备份，写入失败时恢复原数据。
- 正在进行的计时需先结算。未执行预约导入后取消，防止在两台设备重复执行；后续新记录不会自动跨设备同步。
- 安卓使用系统文件管理器保存和选择备份。请先覆盖升级新版 APK，不要卸载旧版或清除数据。
