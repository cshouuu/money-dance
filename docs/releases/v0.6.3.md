# MoneyDance v0.6.3

修复部分用户从旧版本升级后，停留在“导入恢复备份无法读取，请勿清除应用数据”界面的问题。

- 自动识别旧版本保留的导入恢复记录，无需用户提供备份文件或手动修改数据。
- 已经成功完成导入的，保留当前工资、账本等数据，不回滚到导入前。
- 真正中断的导入，按原快照恢复；快照未涉及的新增数据保持原值。
- 保留导入前备份的导出能力，并继续拦截缺失必要字段或格式异常的恢复记录。

## 苹果主屏幕网页版

联网，从原来的 MoneyDance 图标打开，点击“重新尝试恢复”。如仍显示旧界面，从后台完全关闭后重新打开原图标。恢复正常后，进入“设置 → 数据备份与迁移 → 导出备份”。

请勿删除主屏幕应用、清除 Safari 网站数据或手动删除恢复记录。若仍无法进入，请保留现场并反馈。
