# MoneyDance 桌面版 v0.6.1

- 桌宠默认随机播放动作，每段完整播放后切换，避免连续重复；可在“我的桌宠”关闭随机模式，恢复跟随计薪状态。
- 内置角色支持六种动作；导入动作包的全部素材均可参与随机播放，无需先绑定工作状态。摸摸、庆祝互动优先，结束后恢复随机播放。减少动作和系统减少动态效果设置仍生效。
- 新增气泡文案编辑：摸摸、喝水 / 活动、加班关怀、收工休息、里程碑庆祝、专注完成六个场景。每行一句，每场景最多 10 句、每句最多 120 字，触发时随机选择。
- 支持预览、保存和按场景恢复默认（清空后保存）。设置本地持久化，收入汇报保持真实数据，提醒触发时间、免打扰和计薪逻辑不变。

发行目标：Windows x64 / ARM64、macOS Apple Silicon / Intel。安装包使用既有 MoneyDance 数据目录，升级保留已有数据。
