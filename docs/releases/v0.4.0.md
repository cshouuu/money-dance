# MoneyDance v0.4.0 更新说明

这次更新，让不同工作阶段、休息安排和轮班作息都能按自己的规则记录。

## 新增工作旅程

- 记录不同工作阶段，保留各阶段的工资与作息，查看阶段收入和每日明细。
- 支持补录过去的工作、安排下一份工作，以及设置未来的最后任职日；工作间隙自动显示休息状态。

## 支持寒暑假与自定义排班

- 为工作阶段设置寒假、暑假等个人假期，可按正常工资、比例、固定月薪或无薪计算。
- 可选开启手动排班、每周重复或自定义循环，支持超过 24 小时的长班、多段休息和班次补贴。
- 支持临时调班、批量安排、复制前一周和手工确认最终工资；常规规则按生效日期保留历史。
- 首页、日历、工作旅程、账本、心愿和桌面组件同步使用工作与假期安排；跨月正常工时按实际时间拆分。

## 首页与移动端优化

- 移动端底部四个常用入口可自定义。
- 本月战绩支持查看累计工作时长、摸鱼时间和综合时薪，计算明细在卡片内展开。
- 首页心愿卡片新增剩余工作日估算。
- 日历显示固定周末、大小周休息日，以及排班和续班状态。
- 日期、时间和排班入口统一使用 beUI，优化主题切换与数字字体。

排班为可选功能，未开启时继续使用原有作息。正式 Android 包沿用固定签名，可覆盖升级正式版；此前的独立测试版与正式版数据互不共享。
