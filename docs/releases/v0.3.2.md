# MoneyDance v0.3.2

修复手机端长弹窗无法上下滚动的问题。

- 「调整出勤情况」在选择请假等较长表单时，可以正常上下滑动并到达底部保存按钮。
- 同步修复确认操作、账本编辑、开始加班、补记加班、摸鱼时间、上下班时间调整和提前下班弹窗的同类问题。
- 日期 / 时间选择弹窗增加高度限制与整体滚动，避免矮屏或横屏时操作区域超出屏幕；保留日期、时间列的独立滚动。
- 底部功能面板与主题面板按实际标题高度分配内容空间，避免标题说明换行后截断底部内容。
- 下拉选项列表根据展开方向的可用空间限制高度，修复请假类型等长列表末尾选项超出屏幕的问题。

## 验证

- 检查全部 8 类业务弹窗、日期时间选择器、底部面板和下拉列表。
- 浏览器回归覆盖 360×560、360×320 小屏与 1280×800 桌面，验证实际上下滚动和底部按钮可达。
- 499 项测试通过；TypeScript、生产构建和依赖审计通过。
- Android 通过发布流水线检查并使用原有固定签名构建，支持覆盖升级。
- 未连接 Android 真机，未将浏览器移动尺寸回归视为真机触摸或软键盘测试。
