# MoneyDance v0.6.2

薪苦日历已收录 2027 年官方节假日安排，并支持独立更新节假日数据。

- 补齐 2027 年放假及调休补班日期，区分法定带薪日期与普通调休日。
- 在薪苦日历点击“更新官方节假日数据”，即可下载项目维护的最新已核验安排；保存后可离线使用。
- 后续节假日数据可以独立发布，无需重新安装应用。断网、数据异常或存储不足时保留原数据。
- 日历、首页计薪、排班预览和桌面组件使用同一份数据；下载的数据随备份迁移。
- 手工出勤和原有生效日期继续生效，不自动增加加班倍率。
- 更新存在已知漏洞的运行与构建依赖，恢复发布安全审计通过。
