# SalaryFlow — 页面信息架构

## 1. 一级导航

```text
SalaryFlow
├── 今日 / Dashboard
├── 换算 / Converter
├── 摸鱼 / Slacking
├── 物品 / Assets
└── 我的 / Settings
```

桌面端：左侧固定导航。  
移动端：底部固定 5 Tab。

## 2. 今日 / Dashboard

```text
今日
├── 日期 / 问候
├── 今日已赚金额（核心 Hero）
│   ├── 秒薪增长提示
│   ├── 工作日进度条
│   ├── 已计薪时长
│   └── 今日预计收入
├── 指标卡
│   ├── 时间单价
│   └── 今日摸鱼收益
└── 快捷换算
    ├── 咖啡
    ├── AirPods
    └── 手机
```

## 3. 换算 / Converter

```text
换算
├── 新增换算
│   ├── 物品名称
│   ├── 价格
│   ├── 即时所需工作时间
│   └── 保存
└── 我的换算
    ├── 名称
    ├── 价格
    ├── 所需工作时间
    └── 删除
```

## 4. 摸鱼 / Slacking

```text
摸鱼
├── 当前计时状态
│   ├── 计时器
│   ├── 当前摸鱼收益
│   └── 开始/结束
├── 汇总
│   ├── 历史总收益
│   └── 历史总时长
└── 最近记录
```

## 5. 物品 / Assets

```text
物品
├── 新增物品
│   ├── 名称
│   ├── 价格
│   ├── 购买日期
│   └── 分类
└── 物品卡片
    ├── 购买价格
    ├── 已拥有时长
    └── 当前持有成本/小时
```

## 6. 我的 / Settings

```text
我的
├── 工资设置
│   ├── 金额
│   ├── 工资周期
│   ├── 月平均工作日
│   └── 每周工作日
├── 工作时间
│   ├── 上班
│   ├── 下班
│   ├── 午休
│   └── 午休是否计薪
└── 结果预览
    ├── 日薪
    ├── 时薪
    ├── 分钟薪资
    └── 秒薪
```
