# Money Dance 页面原型

## 核心页面

### 今日 / Dashboard
- 顶部核心数字：今天已经赚了多少钱，按时间动态刷新。
- 展示秒薪、工作进度、距离下班时间、今日预计收入和当前收入。
- 首页直接提供摸鱼开始按钮和常用商品工作时间换算。

### 换算 / Converter
- 输入物品名称和价格。
- 输出需要工作的小时、分钟及等价工作日。
- 可保存多个想买的物品并随薪资设置自动重算。

### 摸鱼 / Slacking
- 开始后显示秒级计时器与本次摸鱼收入。
- 刷新或锁屏后基于开始时间戳恢复，不依赖前台持续计数。
- 结束后保存开始时间、结束时间、时长和金额快照。

### 物品 / Assets
- 输入名称、价格、购买日期和分类。
- 显示已持有时间和动态下降的每小时/每天持有成本。
- 未来日期禁止保存。

### 设置 / Settings
- 工资金额、工资类型、月工作日、上下班时间、午休时间、午休是否计薪。
- 保存后立即影响今日收入、商品换算和摸鱼计算。

## 响应式规则
- Desktop：左侧导航 + 主内容区，实时收入数字作为首屏视觉中心。
- Mobile：底部 5 项导航（今日 / 换算 / 摸鱼 / 物品 / 我的）。
- 实时金额仅做视觉高频刷新，业务结果始终由时间戳推导，不累计浮点增量。
