# MoneyDance Windows 与桌边搭子

Windows 10/11 x64。复用 Web 产品全部业务页面和现有计薪规则，桌面宿主使用 Electron；不要求注册或连接服务器。桌宠在独立的透明置顶窗口中显示，可以拖动位置，主窗口关闭后收入同步继续运行。任务栏右侧的托盘菜单可重新打开应用、显示/隐藏桌宠、找回屏幕外的桌宠或彻底退出。

## 开始使用

1. 安装 `MoneyDance-0.4.0-windows-x64.exe`，打开 MoneyDance，完成原有薪资和作息设置。
2. 左侧点击「桌边搭子」。默认小薪已经可用，也可以「选图并自动提取主体」。
3. 选择 PNG/JPG/WebP（不超过 15 MB、2500 万像素）。U²-NetP 在本机提取显著主体，原始照片不会上传，也不会修改。
4. 在四种动作间切换，点击预览中的桌宠可以试试摸摸；满意后点击「就用它，放到桌面」。取消/失败不会替换现有桌宠。
5. 支持直接使用已经抠好的透明 PNG/WebP。可换回默认小薪，操作会先询问确认。

建议图片中只有一个清晰主体。轻量模型适用于宠物、人物和玩偶，复杂背景、多个主体、细毛发可能有残留或误裁；可以换图或预先准备透明图片。当前动作是对提取主体进行形变、位移、旋转及配件动画，并非从单张图片生成逐帧角色骨骼动画。

## 陪伴设计

| 场景 | 动作 | 产品联动与回应 |
| --- | --- | --- |
| 正常工作 | 呼吸、轻轻起伏、小绿芽 | 显示本工作日计薪；按设置每 15/30/60/120 分钟汇报 |
| 摸鱼记录进行中 | 左右摇摆、小鱼和音符 | 陪伴放松；菜单打开原有摸鱼记录页，不改变计薪规则 |
| 加班记录进行中 | 慢慢点头、热饮、星光 | 本次加班计薪单列；满 1 小时提醒喝水，之后每小时提醒休息，不奖励加班时长 |
| 午休、暂停、下班或休息日 | 打盹、呼吸、月亮 | 停止自动收入/活动提醒；从忙碌转入休息时给一次温柔回应 |
| 摸摸 | 轻跳、爱心 | 随机暖心回应，不以连续打卡制造负担 |
| 收入/心愿里程碑 | 轻跳庆祝 | 收入跨过百元或首个未购买心愿完成时提醒；打开旧记录不会补发大量庆祝 |
| 专注 25 分钟 | 保留当前业务动作，显示倒计时 | 到点提醒休息；独立于工作/摸鱼/加班记录，不会擅自开始或结算工作 |

桌宠点击金额可以立即汇报，右键或点击 `•••` 展开菜单。拖动后保存位置，断开外接显示器会将它移回可见区域。空白处尽可能透传鼠标；主体及交互控件区域接受鼠标操作。全屏独占应用或受系统保护的界面可能覆盖桌宠。

## 提醒与隐私

- 默认每 60 分钟汇报收入、每 50 分钟提醒喝水/活动，只在工作/摸鱼/加班状态自动提醒。
- 默认 23:00–08:00 免打扰。支持跨午夜区间；开始与结束相同时表示全天免打扰。
- 可安静陪伴 30 分钟，亦可关闭自动汇报、活动提醒、暖心关怀或里程碑。
- 不积压错过的提醒：休眠恢复、重新打开、免打扰结束后，不集中弹出历史通知。专注计时使用绝对时间，睡眠结束后到期只提示一次；免打扰内到期则安静完成。
- 语音与 Windows 系统通知默认关闭。语音使用系统安装的中文语音；没有可用语音时仍可查看气泡。系统通知受 Windows 通知设置影响。
- 「隐藏收入金额」同时隐藏桌宠金额和提醒中的收入数额。它只保护桌宠区域，主应用仍显示正常业务数据。
- 「减少动作」停止动画，并自动尊重系统减少动态效果偏好。
- 开机启动默认关闭，用户开启后仅安装版注册登录启动；主窗口在登录启动时保持隐藏。
- 模型随安装包携带，运行与抠图均无需联网；模型首次**开发构建**时从上游下载并校验 SHA-256。

## 业务规则与数据

工作金额直接调用 `summarizeTodayWork`，工作状态额外判断真实工作时间片，所以午休不会被误识别为正在工作。薪资、节假日、出勤覆盖、排班、工作旅程、生活成本和弹性工时沿用原有规则。加班状态以用户主动开启的加班记录为准，不会根据钟点擅自开始加班。本次加班金额使用记录开始业务日的工资与用户选择的无薪/倍率/固定金额方式；不把摸鱼金额重复加进工资。

Windows 使用固定的 `moneydance://app` 本地页面来源保存业务数据，普通应用升级保留此来源。Windows 数据位于 `%APPDATA%/MoneyDance`，桌宠配置与图片为 `desktop-pet.json`、`desktop-pet.png`。安装卸载默认不删除应用数据。

Web、Android 和 Windows 使用独立本地存储，不会自动互相导入或同步。基础功能迁移指全部业务能力在 Windows 中复用；本次不引入跨端云同步或旧端数据迁移。

## 本地开发与打包

要求 Windows、Node.js 22.12+、npm。CPU 即可，不需要 CUDA、Python 或显卡。

```powershell
npm ci
npm run dev:desktop
```

`dev:desktop` 先构建共享核心及 Web，然后复制到桌面包，验证/准备模型和图标，再运行 Electron。Web 代码修改后重新执行命令。

```powershell
npm run build:windows
```

生成 `apps/desktop/release/MoneyDance-0.4.0-windows-x64.exe`（NSIS 用户级安装器），以及 `win-unpacked` 可直接运行的目录。不要只复制 `MoneyDance.exe`，免安装运行需要整个 `win-unpacked` 目录。模型及运行库包含在包内。

当前构建为未签名开发版，没有配置 Windows 代码签名证书，也未提供自动更新。正式分发前应在可信构建环境接入组织的 Windows 签名流程；安装覆盖更新保留本地数据。未自动上传到 GitHub Releases 或其他渠道。

## 验证

```powershell
npm test
npm run typecheck
npm run build
npm run prepare:assets -w @salary-flow/desktop
npm run test -w @salary-flow/desktop
node apps/desktop/scripts/verify-package.cjs
$env:MONEY_DANCE_SMOKE='1'
npm run start -w @salary-flow/desktop
```

集成测试使用临时配置目录，不修改真实用户数据；测试结束自动退出，截图在 `output/windows-pet-*.png`。覆盖真实 Electron 窗口、托盘后台同步、IPC 权限、页面路由刷新、金额隐藏、专注/免打扰、真实模型抠图与持久保存。`verify-package.cjs` 需要先完成打包，启动真正的 `win-unpacked/MoneyDance.exe` 验证 ASAR 中的模型和原生库，并退出重启验证图片/偏好持久化。控制台会出现两个预期的拒绝日志，对应恶意设置写入和外部路由测试。模型未准备时，常规测试跳过模型集成用例，Windows CI 会先准备模型再运行。

`.github/workflows/build-windows.yml` 在相关 PR 或手工触发时执行 Windows 测试和打包，上传安装器、SHA-256 和预览截图为构建产物。不会自动发布正式版本。

## 架构

- `apps/desktop/src/main.cjs`：窗口、托盘、受限 IPC、模型工作线程、持久化。
- `apps/desktop/src/reminders.cjs`：去重、节流、跨日免打扰和关怀策略。
- `apps/desktop/src/extract.cjs`：sharp 图片解码与 U²-NetP CPU 推理。
- `apps/web/src/components/DesktopController.tsx`：在后台读取原有本地业务状态，按秒同步金额；心愿进度按分钟计算。
- `apps/web/src/pages/DesktopPet.tsx`：创建、预览、装扮与提醒偏好。
- `apps/web/src/pet/`：独立透明窗口及可复用角色动作。

前端无 Node 权限，启用沙箱与上下文隔离；IPC 验证发送窗口与顶层来源。图片只通过本地文件选择器读取，渲染进程不能传入任意文件路径；选图限大小、像素及格式，推理超过 90 秒终止，可主动取消。主窗口崩溃时重载，桌宠会将陈旧金额标为「正在对表」。
