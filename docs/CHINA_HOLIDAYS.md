# 官方节假日数据

薪苦日历内置 2025–2027 年国务院公布的中国大陆放假及调休补班安排。2027 年来源为[国办发明电〔2026〕10号](https://www.gov.cn/zhengce/content/202611/content_7085101.htm)，可对照[人社部转载全文](https://chinajob.mohrss.gov.cn/h5/c/2026-11-09/635850.shtml)。

在薪苦日历点击「更新官方节假日数据」，应用会联网读取项目维护的已核验数据，校验后保存到本机。网页、PWA、安卓和桌面端共用这一入口；下载成功后可以离线使用。此按钮不直接抓取政府网页，未收录的年份继续按用户的工作周和排班安排计算。

数据与应用版本独立。首次使用此功能需要安装包含按钮的应用版本；之后更新数据无需重新安装应用。发布新年份的数据仍需维护者核对官方通知。

## 数据与计薪

- 数据文件：`apps/web/src/lib/chinaHolidays.data.json`，同时用作应用离线基线和独立发布的内容。
- 每年包含 `sourceUrl`、放假区间 `holidays`、法定带薪日期 `statutoryDates` 和补班日 `adjustedWorkdays`。
- 法定日期按[《全国年节及纪念日放假办法》](https://app.www.gov.cn/govdata/gov/202411/12/521605/article.html)核对；长假中的周末和调休日不应全部标为法定带薪日期。
- 手工出勤、已有工作记录及排班优先级沿用现有业务规则。更新不会改变用户的启用开关或生效日期，也不会自动增加加班倍率。
- 数据更新会重新计算生效日期内、依赖官方安排的自动计算结果；生效日期之前的日期不受影响。手工记录保持原样。
- 已下载数据随备份文件迁移，避免跨设备计算时缺失已收录年份。旧备份没有此项时仍可导入，使用内置数据并可重新更新。
- 网络错误、超时、非法日期、休假与补班冲突、缺失已有年份或保存失败，均保留本机数据；旧版本数据不会覆盖较新版本。

## 后续只发布数据

1. 核验新年度官方公告，在 JSON 中保留既有年份并增加新年度，填写政府原文链接。跨年区间按自然年拆分。
2. 按 `YYYY.修订号` 提升 `version`，如 `2028.1`；同年更正使用更高修订号，不能原地修改同一版本。
3. 执行 `npm run test -w @salary-flow/web -- src/lib/chinaHolidays.test.ts`。
4. 将数据文件合入 `main`，自动触发 `Publish official holiday data` 工作流，也可在 `main` 手动运行该工作流。
5. 工作流使用现有 Cloudflare 凭据，只向 `money-dance-releases` 的 `data/china-holidays.json` 写入 JSON，并核对公开响应。无需创建应用标签、构建安装包或重新部署网页。首次功能发布需要先部署新增的 Pages Function。

公开端点：`https://money-dance-6gl.pages.dev/holidays/china.json`。响应允许跨域读取并禁止 HTTP 缓存；客户端不携带用户数据或凭据。PWA 的静态资源缓存不会拦截此数据请求。
